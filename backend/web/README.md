# OUTOFSTOCK 웹 화면 — 서버 연동판

팀이 확정한 화면(index · learn · news · practice · mypage · **invest**)과 새 '실시간 종목'(stocks) · '양봉이 꾸미기'(avatar)를 **겉모습 그대로** 두고,
예시 데이터와 localStorage 를 백엔드 API 로 바꾼 판이다. 서버가 이 폴더를 그대로 내보낸다
(`/` · `/learn.html` · `/news.html` · `/practice.html` · `/invest.html` · `/mypage.html` · `/stocks.html` · `/avatar.html`).

- 팀 저장소의 화면 파일 = 백엔드 저장소(stock-backend)의 `web/` 폴더. 아래 `app/…`·`tools/…` 경로는 백엔드 저장소 기준이다
  (팀 저장소에는 이 문서가 `백엔드연동_안내.md` 로 들어간다).
- 화면 코드 안에서 바뀐 곳은 `[백엔드 연동]` 주석으로 표시해 두었다.
- 공용 코드는 `assets/oos/runtime.js` 한 파일 — 모든 화면이 가장 먼저 불러온다.
  (2026-11) 런타임이 이 브라우저 전용 키(꺼낼 수 없는 ECDSA 키)로 로그인·갱신·변경 요청에 서명을 붙인다 — 쿠키를 훔쳐 다른 기기에서 써도
  송금·갱신이 안 된다. 화면 코드는 바꿀 것 없음 — **서버 호출은 꼭 `OOS.api` 로**(직접 `fetch` 하면 서명이 빠져 돈 동작이 401).
- **파일로 열어도(더블클릭) · Live Server · GitHub Pages 로 열어도 된다** — 우리 서버 없이 열면 시안의 예시 데이터로 보인다(디자인 작업용).
  로그인·저장은 우리 서버가 내보낸 화면에서만(서버가 `<head>` 에 `<meta name="oos-server">` 표식을 붙이고, 화면은 이 표식이 있을 때만 API 를 부른다 —
  **이 표식을 파일에 직접 넣지 말 것**).

## 화면을 고칠 때 지킬 것 (서버 보안 규칙 — 어기면 그 버튼이 브라우저에서 막힌다)

1. **`onclick="…"` · `onsubmit="…"` 같은 인라인 핸들러 금지** → `data-on="함수(인자)"` 로 쓰고, 그 페이지 스크립트 끝의
   `OOS.actions({ 함수, … })` 에 이름을 넣는다. 폼은 `data-on-submit="event.preventDefault(); 함수()"`,
   모달 바깥(배경) 클릭으로 닫기는 `data-on-self="closeX()"`.
   - 인자로 쓸 수 있는 것: `'문자열'` · 숫자 · `true/false/null` · `this` · `event` · `this.dataset.키`
2. **외부 스크립트 금지** — `<script src="https://…">`(CDN) 는 막힌다. 파일은 `assets/` 아래에 두고 상대 경로로.
3. **`innerHTML` 에 넣는 값은 `esc()`** — `<script>` · `on…=` · `javascript:` 가 섞인 HTML 은 브라우저가 막고(콘솔 오류) 서버에 보고된다.
4. **서버 호출은 `OOS.api('/경로', { method: 'POST', body: {…} })`** — 쿠키 · CSRF · 토큰 갱신 · 비밀번호 재확인 창을 알아서 한다.
   로그인 여부는 `OOS.loggedIn()` · `OOS.user`, 로그인/로그아웃이 바뀌면 `OOS.on('session', fn)`.
5. **새 페이지를 만들면** 서버 허용 목록(`app/webui.py` 의 `PAGES`)에 이름을 넣어야 열린다.
6. **데이터 파일을 바꾸면** 서버 사본도 다시 만든다(시험이 어긋남을 잡는다):
   - `assets/terms.js`(용어) → `python tools/build_learn_terms.py <팀 저장소 경로>`
   - `assets/daily-quiz.js`(퀴즈) → `python tools/build_daily_quiz.py`
   - `assets/avatar-items.js`(양봉이 아이템 그림·이름·**가격**) → `python tools/build_avatar_items.py` — 서버는 이 사본의 가격으로 돈을 뺀다.
     잊으면 화면은 새 가격을 보여 주고 서버는 '가격이 바뀌었어요(409)'로 사기를 거절한다(돈이 잘못 빠지지는 않는다).
   - `index.html` 의 설문 문항(`SURVEY_BANK`)은 서버 문항과 같은 순서·문구여야 한다(Q1~Q20 — 채점은 서버).
   - **모의투자 시즌 파일(`data/season_XX.js`)은 화면 폴더에 넣지 않는다** — 미래 봉이 다 들어 있어 누구나 내려받아 미리 볼 수 있다.
     서버에는 `python run.py vmarket-import season_11.json …`(생성기의 .json 이나 .js 그대로)로 넣는다 — 형식·가격을 검사하고,
     이미 시작한 시즌은 바꿀 수 없다. 시즌 10(2027-01-04 주)까지 들어 있고, 다음 시즌이 없으면 금요일 18:00 에 운영 경보가 간다.
7. **돈·순서·시간 규칙은 서버가 정한다** — 화면에서 계산한 가격·잔액·정산을 서버에 보내지 않는다(서버가 다시 계산한다).
   모의투자 주문은 '화면이 본 봉 번호(bar)'만 보내고 체결가는 서버가 그 봉 종가로 정한다(새 봉이 나왔으면 409 → 화면을 새로 고친다).

## 팀 저장소에서 고친 화면을 서버에 반영하기
```bash
python tools/sync_web.py <팀 저장소 폴더>            # 미리 보기 — 무엇이 바뀌는지 + 규칙 위반 경고(onclick·외부 스크립트)
python tools/sync_web.py <팀 저장소 폴더> --apply    # web/ 로 복사(화면·assets·images 만 — 자료조사·README 는 안 가져옴)
python tools/check_frontend.py && pytest -q tests/test_web_security.py tests/test_web_front.py tests/test_accessibility.py
python tools/make_installer.py                      # → VM 에서 bash deploy/vm.sh update ~/install_outofstock_full.sh
```
팀 저장소에 `assets/oos/runtime.js` 가 없으면(연동 전 시안) 멈춘다 — 덮어쓰면 로그인·저장이 끊기기 때문.
`terms.js` 가 바뀌었으면 도구가 용어 사전 재생성 명령을 알려 준다.

## 시안에 아직 화면이 없는 것(서버 API 는 준비됨)
- 헤더 검색창 — 공용 런타임이 자동완성(`/search/suggest`, 국내·해외·초성)을 붙인다. 고르면 `stocks.html?mkt=…&code=…`
- '비밀번호 찾기' — 메일 발송 기능이 없어 안내 문구만(로그인한 뒤 비밀번호 변경은 마이페이지)
