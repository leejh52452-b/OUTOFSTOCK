# 소프트웨어 개발보안 — 설계 20 · 구현 49 보안약점 대응표

기준: 행정안전부·KISA 「소프트웨어 개발보안 가이드」(2021) — 설계단계 보안약점 20개, 구현단계 보안약점 49개(7개 유형).
판정: **대응**(코드·시험으로 확인) · **해당 없음**(그 기능·언어 특성이 없음 — 이유 기재). 자동 점검은 CI 의 bandit(중간 이상)·
pip-audit·숨은 문자 검사(`tools/security_scan.sh`), ruff(F: 정의 안 된 이름·중복 정의 등)가 같이 본다.
