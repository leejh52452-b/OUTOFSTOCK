# 5거래일 수익률 예측 — 검증 체계 `ret5-1.0`

## 질문을 바꿨다
"주가를 맞힐 수 있나"가 아니라 **"맞힌다고 착각하지 않으려면 어떻게 검증해야 하나"**.
목표: 종목의 다음 5거래일 수익률이 그날 전 종목 중앙값보다 높을까(시장 전체 등락을 뺀 상대 성과, 0/1).

## 두 가지 검증을 같은 데이터에 나란히
| 방식 | 하는 일 | 문제 |
|---|---|---|
| A 무작위 K-겹 | 행을 섞어 5겹 | 5일 목표가 날마다 4일씩 겹친다 → 이웃 날짜(거의 같은 피처·비슷한 정답)가 학습·시험에 나뉘어 **외운 것이 실력처럼** 보인다 |
| B 시간순 전진 + 퍼지 | 과거로 학습 → 다음 구간 시험, 시험 직전 5거래일 학습 표본은 버림(목표 기간 겹침) | 실제로 쓸 때와 같은 조건 |
누수 크기 = A 의 AUC − B 의 AUC. 기준선(무작위·20일 모멘텀·5일 반전)을 못 넘으면 '예측력 없음'이 결론.

## 결과
### 합성 데이터 1 — 예측할 것이 없는 시장(순수 무작위 보행, 120종목 × 900일)
| | AUC | 일별 IC t값 | 상·하위 20% 5일 수익률 차(비용 전→후) |
|---|---|---|---|
| A 무작위 K-겹 | 0.533 | **20.4** | +86.1bp → +61.1bp |
| B 시간순 + 퍼지 | 0.498 | −1.4 | −5.7bp → −30.7bp |
**잡음뿐인 데이터에서 무작위 분할은 'IC t값 20, 비용 뒤에도 주당 0.6%'라는 가짜 전략을 만들었다.** 시간순 검증은 정직하게 0.5.
### 합성 데이터 2 — 약한 모멘텀 신호를 심은 시장
시간순 검증 AUC 0.577(신호를 잡음). 그러나 **20일 모멘텀 한 줄(0.589)을 못 이김** → 판정 '기준선 못 넘음'. 복잡한 모형이 단순 규칙보다 낫다는 보장은 없다.
### 실데이터 — VM 에서
```bash
.venv/bin/python run.py return-validate      # 거래대금 상위 300종목 × 5년, 결과는 /models/return·화면 '데이터 분석'
```

## 한계(결과와 함께 반드시 적는다)
- 생존 편향: 현재 상장 종목만 고르면 과거 수익이 부풀려진다 → 분석 계층은 상장폐지 종목도 보존.
- 거래비용·슬리피지·호가 단위: 0.25% 왕복만 가정. 소형주는 더 크다.
- 체제 변화: 한 기간의 신호가 다음 기간에 사라진다 → 여러 기간 재현 필요.
- 다중 검정: 설정을 여러 번 바꿔 가장 좋은 것만 고르면 우연을 고른 것 — 시험 구간은 마지막에 한 번만 본다.
