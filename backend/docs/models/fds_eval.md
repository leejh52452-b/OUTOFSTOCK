## 규칙

| 키 | 점수 | 설명 |
|---|---|---|
| velocity | +40 | 최근 10분 송금 5건 이상 |
| spike | +25 | 평소 송금액(중앙값)의 5배 이상(30만원 이상) |
| drain | +20 | 송금 후 잔액 1% 미만(100만원 이상 송금) |
| new_payee | +20 | 처음 보내는 사람에게 100만원 이상 |
| ato_session | +20 | 세션 IP 대역 변경(계정 탈취 의심) |
| recent_pw | +15 | 24시간 안 비밀번호 변경 |
| fan_in | +35 | 받는 사람이 최근 1시간 5명 이상에게서 받음 |
| round_trip | +20 | 30분 안 반대 방향 송금(100만원 이상) |
| charge_out | +25 | 1시간 안 충전(50만원 이상)한 금액과 비슷한 금액을 바로 송금 |
| night_large | +10 | 새벽(01~05시) 100만원 이상 |

결정: 70점 이상 차단 · 40점 이상 추가 인증.

**한계** — 합성 분포에서의 수치는 실제 성능이 아니다. 알려진 수법(계정 탈취 후 인출·대포통장 집금·연속 인출·충전 후 즉시 이체·자전거래)을 잡는지, 정상 경계 사례(중고거래 큰 송금·모바일 IP 변경)를 막지 않는지를 회귀 시험하는 용도다. 운영에서는 fds_decision 기록과 /admin/fds 요약으로 오탐을 검토해 임계값을 조정한다.
