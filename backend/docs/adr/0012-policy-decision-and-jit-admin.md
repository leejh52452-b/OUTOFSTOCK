# ADR-0012 인가는 코드와 분리된 정책(PDP)으로, 모든 경로는 집행 지점(PEP)을 지나고, 관리자는 '켤 때만' 관리자다

| 항목 | 내용 |
|---|---|
| 상태 | 채택 · 2026-10-20 |
| 범위 | 제로트러스트 — 애플리케이션·식별자 |
| 코드 | `app/security/policy.json` · `pdp.py` · `pep.py` · `rbac.py` · `deploy/nginx.conf`(관리 기기 mTLS) |
| 시험 | `test_zero_trust.py`(경로 전수·기본 거부·판정 표·JIT·2인 승인·기기 인증서) |

## 맥락
권한 확인이 라우트마다 흩어져 있었고(로그인 여부 `if`), 관리자는 `ADMIN_USERS` 환경변수에 이름이 있으면 **항상** 관리자였다.
새 경로를 만들며 확인을 빠뜨리면 그대로 열린다. 2단계 인증도 없었다.

## 결정
- **PDP** — `policy.json` 에 동작 25개: 주체 종류(익명·게스트·사용자), 역할, 최소 인증 강도(AAL), 추가 인증 조건(위험 신호·금액),
  목적 필수 여부, CSRF 필요 여부. **목록에 없는 동작은 거부**, 파일 형식이 틀리면 서버가 뜨지 않는다(안전 실패).
  판정마다 정책 버전·SHA-256 을 기록 — 어떤 정책으로 결정했는지 추적.
- **PEP** — 모든 API 경로가 `pep.actor("동작")` 의존성을 선언한다. 선언이 없거나 정책에 없는 이름이면 거부.
  순서: 자격 꺼내기(쿠키/Bearer) → 세션 확인 → PDP → CSRF·Origin → 위험 신호·IP 차단 → 관리 동작이면 기기 인증서 확인.
- **관리 역할(RBAC + JIT)** — '자격'과 '활성'을 나눈다. 자격은 2인 승인(요청자 ≠ 승인자 ≠ 대상자)으로만, 90일 만료.
  쓰려면 사유 + TOTP 를 마친 세션에서 활성 → **30분 뒤 자동 회수**, 세션 폐기·로그아웃 시 즉시 회수.
- **관리 기기** — nginx 가 사설 CA 기기 인증서를 확인하고 결과 헤더를 덮어쓴다. 앱은 `ADMIN_REQUIRE_CLIENT_CERT=true` 면
  그 헤더를 다시 본다(앱이 127.0.0.1/내부망에만 있을 때만 의미 — `vm.sh` 가 어긋난 구성을 경고).

## 검토한 대안
| 대안 | 버린 이유 |
|---|---|
| 라우트별 데코레이터·`if` | 빠뜨려도 아무도 모른다 — '선언 안 하면 거부'가 핵심 |
| OPA·Casbin 등 외부 정책 엔진 | 동작 25개 규모에 프로세스·언어 하나가 더 늘어난다. JSON + 작은 PDP 로 같은 성질(분리·기본 거부·버전) |
| 상시 관리자 + 2단계 | 권한이 늘 켜져 있어 탈취 시 피해가 크다. 사용 시간·사유가 남지 않는다 |

## 결과
- 경로 120개 전부 동작 선언(시험이 강제). 기각 기능 제거로 경로 175 → 120(공격 표면 31% 감소).
- 관리 화면을 쓰려면 매번 '활성'이 필요해 번거롭다 — 의도된 마찰(감사 기록에 사유가 남는다).
