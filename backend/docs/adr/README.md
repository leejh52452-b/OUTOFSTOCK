# 설계 결정 기록(ADR)

'왜 이렇게 만들었나'를 한 결정당 한 장으로 남긴다. 형식: 맥락 → 결정 → 검토한 대안 → 결과(숫자·감수한 점) → 검증(다시 재는 법).
번호는 코드 주석에서 그대로 참조한다(예: `sql/migrations/V003` → ADR-0003). 결정이 바뀌면 고치지 말고 새 ADR 을 쓰고 상태를 '대체됨'으로.
