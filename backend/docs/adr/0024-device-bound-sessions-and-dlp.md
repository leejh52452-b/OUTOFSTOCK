# ADR-0024 탈취·유출 내성 — 세션을 기기 키에 결속(DPoP 방식) · 자유 입력의 중요정보 가림(DLP)

## 맥락
제로트러스트 자가 점검에서 단말 D1(세션 ↔ 기기 결속)은 '부분'이었다 — 기기 지문(브라우저·OS 계열)은 흉내 낼 수 있다.
HttpOnly 쿠키는 스크립트(XSS)로는 못 읽지만, 감염 PC·악성 확장 프로그램·브라우저 프로필 백업으로 **통째로 복사**될 수 있다.
복사된 갱신 쿠키가 있으면 공격자는 12시간 동안 세션을 늘리며 송금할 수 있었다. 데이터 DA4(유출 방지)도 '부분' —
채팅·송금 메모는 자유 입력이라 사용자가 주민등록번호·카드번호를 붙여 넣으면 그대로 저장·백업·상대방 화면으로 퍼졌다.

## 결정
1. **기기 키** — 화면 런타임이 WebCrypto 로 ECDSA P-256 키를 `extractable:false` 로 만들어 IndexedDB 에 객체로 둔다(스크립트도 개인키를 못 꺼냄).
2. **결속** — 로그인 요청의 DPoP 증명(공개키 + 서명)에서 공개키 지문(jkt, RFC 7638)을 세션에 저장.
3. **증명이 필요한 곳** — 토큰 갱신, 그리고 policy.json `bind:"device"` 동작(송금·충전·구매·모의투자·탈퇴·비밀번호·2단계 인증·모든 관리 동작).
   증명 = 그 키로 서명한 JWS(메서드·경로·발급 시각 ±5분·1회용 ID — `dpop_jti` 에 10분 보관해 재사용 거부).
4. **대응** — 다른 키로 서명했거나 키 없이 갱신 → 탈취로 보고 세션 종료 + 규칙(그 사용자 전 세션 종료). 돈 동작에 증명이 없으면 401(종료하지 않음 — 화면 오류일 수 있다).
   깨진·오래된 증명은 그 요청만 거절(런타임이 서버 시각으로 맞춰 한 번 다시 보낸다 — PC 시계가 틀려도 동작).
5. **호환** — 결속 안 된 세션(앱 Bearer·키를 못 만드는 브라우저)은 예전 통제(기기 지문·CSRF·추가 인증)로 동작. 겉모습 변화 없음.
6. **DLP** — 채팅·송금 메모를 저장하기 전에 주민등록번호(생년월일이 실제 날짜 + 성별 자리 1~8)·카드번호(13~19자리 + 룬 + 국제 앞자리)를
   되돌릴 수 없게 가리고, 가린 사실만 보안 이벤트(종류·필드 — 내용 없음). 응답에 `masked` → 화면이 '가려서 보냈어요'. 같은 규칙을
   로그·운영 알림의 마지막 출구(`redact`)에도. 금액·전화번호·계좌번호는 형식만으로 구분되지 않아(오탐) 가리지 않는다.

## 검토한 대안
| 대안 | 버린 이유 |
|---|---|
| 모든 요청에 증명 | 조회까지 서명하면 요청마다 서명·검증·재사용 기록(DB 쓰기). 훔친 접근 토큰은 최대 10분·조회만 가능 — 돈·갱신·관리에 집중 |
| 서버 nonce(RFC 9449 `DPoP-Nonce`) | 왕복이 하나 늘고 다중 워커에서 nonce 공유가 필요. 발급 시각 창 + 1회용 ID(DB)로 같은 재사용 방어 |
| htu 전체(스킴·호스트) 비교 | nginx 뒤에서 http↔https·포트가 달라 어긋난다. 출처는 CSRF·Origin 검사가 이미 본다 — 경로만 비교 |
| mTLS 클라이언트 인증서(일반 사용자) | 사용자마다 인증서 발급·설치가 필요 — 관리 기기에만(ADR-0012). WebCrypto 는 설치 없이 같은 '키 소유 증명' |
| FIDO2 패스키 | 피싱 저항 '인증'(로그인)에는 더 강하다 — 다음 단계. 결속은 로그인 이후 '세션 탈취'를 막는 다른 층이라 둘 다 필요 |
| DLP 를 응답 전체 검사로 | 이미 저장된 뒤라 늦고, 응답마다 정규식 비용. 저장 전(입구)에서 막고 출구(로그·알림)는 안전망 |

## 결과
- 쿠키를 통째로 복사한 다른 기기: 송금 401(`dpop_required`) · 다른 키로 서명 401(`dpop_mismatch`, 세션 종료) · 갱신 → 세션 종료(E2E 실측).
- 같은 기기: 아무것도 바뀌지 않는다(증명은 런타임이 자동). RFC 9449 예시 키의 지문이 표준 값과 일치 — 다른 구현과 맞물린다.
- 자가 점검: 단말 D1 부분 → 이행, 데이터 DA4 부분 → 이행(범위: 자유 입력·로그·알림).

## 한계
- 키는 브라우저 프로필 안에 있다 — 공격자가 그 PC 를 원격 조종하면 같은 브라우저로 요청할 수 있다(단말 보안 D3 — MDM/EDR 영역).
- 결속 안 된 세션은 기존 통제만. 웹 화면은 항상 결속을 시도하므로 대상은 앱(Bearer)·아주 오래된 브라우저.
