# OUTOFSTOCK 리디자인 — 준혁 PRD(디자인)에 맞춰 전체 개편

> **기록 문서(2026-09 리디자인 당시)** — 여기 나오는 일부 기능(게임·단기 시뮬·아바타·커뮤니티 등)과 인증 방식(24시간 Bearer 토큰)은
> 2026-10-20 에 정리·교체됐다. 지금 구조는 `README.md`, 프론트 연동은 `frontend/FRONTEND_API_GUIDE.md`, 보안은 `docs/security/README.md`.

프론트 담당이 준 Claude Design PRD("OUTOFSTOCK 기준 PRD")를 기준으로, 기존 백엔드 repo
(`stock-backend`)를 **덮어쓰지 않고** 네 이디엄(`db.query`/`transaction`, 단일 MetaData,
`@app` 라우트, `require_auth`, `game.py`의 원자성·멱등성·OCC)에 맞춰 확장했다.

## 화면(디자인 그대로 6+2)

- **홈** — 지수(코스피·코스닥·환율·국고채) · 진행 중 실습 배너 · 실시간 종목순위(탭) ·
  주요 뉴스 · 안정형 추천상품(위험등급) · 오늘의 AI 뉴스 픽(호재/악재) · 오늘의 학습 · 최근 학습
- **학습** — 팀 `learn.html`(주식 용어 사전) 틀: 검색(초성)·초급/중급·ㄱ~ㅎ/A-Z·주제 필터, 양봉이 비유 카드, 연관 용어 점프,
  '이해했어요'·학습 현황(로그인 시 계정 저장), 오늘의 용어, 실습 연결. 용어 141개 = 팀 terms.js 116 + 팀 「주식 기초 용어 사전」 docx 23
  (겹치는 77개는 '더 알아보기'로 읽는 법·오해 주의) + 기존 체결강도·다이버전스. 보조지표·매매기법의 계산/기간/보는 것/주의·신호/위험은 해당 카드 '더 알아보기'로 유지
- **실습(핵심 신기능)** — 과거 사례 목록(난이도·상태·지표) + **진행 화면**: 하루(1일/5일) 진행,
  미래 은닉, 학습목표, TradingView 캔들+SMA/RSI/거래량, 내 계좌, 주문(매수/매도·25/50/75/최대)
- **종목** — 순위표(거래대금·거래량·시총·상승률·하락률 + 검색) → **종목 상세**(펀더멘털 + 캔들차트)
- **뉴스** — 팀 `news.html` 틀: 오늘의 이슈 TOP · 핵심 테마 TOP5(스파크라인) · 주간/월간 랭킹 · 실시간 뉴스(더 보기).
  조회수는 공개되지 않아 **보도량(관련 기사·언론사 수)** 기준. 호재/악재 태그·필터, 관련 종목 칩, AI 뉴스 픽 추가. 제목·출처·링크만(본문 없음)
- **로그인** — 이메일+비밀번호(pbkdf2·토큰)

색: **빨강=상승/이익, 파랑=하락/손실**(한국식). 포인트 `#2563eb`. 차트 = TradingView Lightweight
Charts(로컬 번들 `app/static/vendor/lightweight-charts.js`, CDN 불필요).

## 실행

**DB: PostgreSQL 전용(SQLite 미사용).** compose 로 DB 먼저 띄운다.

```bash
docker compose up -d db                # PostgreSQL 16 (localhost:5432, oos/oos/outofstock) + outofstock_test
pip install -r requirements.txt        # psycopg 포함(libpq 별도 설치 불필요)

# (A) 오프라인 미리보기 — 생성 데이터로 전 화면
python run.py demo
uvicorn app.api:app --reload           # http://127.0.0.1:8000/app

# (B) 실데이터 — .env 에 KRX_API_KEY / DART_API_KEY / KIS_* / UNIVERSE_TOP_N=150
python run.py real                     # KRX 시세·지수 + 실습 + DART 재무 + 뉴스(top-N)
#   또는 개별: fetch-market · fetch-practice · fetch-dart · fetch-news
python -m app.collectors.realtime      # KIS 실시간 체결가(장중 상시, 별도 프로세스)
uvicorn app.api:app --reload
pytest -q                              # 573 passed (outofstock_test DB, 외부 네트워크 호출 없음)

# 앱까지 컨테이너로:  docker compose --profile full up
```

> DB 기본 접속값(`oos/oos@localhost:5432/outofstock`)은 `app/config.py` 기본값과 compose 가 일치 →
> 로컬에서 `DATABASE_URL` 안 적어도 붙는다. 스키마는 `python run.py initdb`(또는 demo/real)가 만든다 —
> API 서버도 시작할 때 같은 `init_db()`(무손실·멱등, 동시 실행은 advisory lock 으로 줄 세움)를 돌린다 — 그래도 업데이트 후엔
> `initdb` 1번을 권장(마이그레이션 결과를 화면에서 확인). 커넥션 풀 + `pool_pre_ping`.

### 데이터 소스 (네이버 미사용)

| 데이터 | 소스 | 방식 |
|---|---|---|
| 시세·지수·유니버스 | **KRX 정보데이터시스템 OpenAPI** | base `data-dbg.krx.co.kr/svc/apis/`, 헤더 `AUTH_KEY`, `basDd=YYYYMMDD` 하루씩. 주식 `sto/stk_bydd_trd`·`sto/ksq_bydd_trd`, 지수 `idx/kospi_dd_trd`·`idx/kosdaq_dd_trd`. 시총 상위 `UNIVERSE_TOP_N`(예:150)을 `stock` 테이블에 적재. 하루 1만 콜 |
| 재무(PER/PBR) | **DART** | `fnlttSinglAcnt` → 순이익·자본총계. **PER = 시총/순이익, PBR = 시총/자본총계** |
| 뉴스 | **Google News RSS** | 종목별 헤드라인(네이버 아님) |
| 실시간 체결가 | **KIS** | 웹소켓(`app/collectors/realtime.py`), 장중·`KIS_APP_KEY` 필요 |
| (오프라인) | **gen** | 결정론적 생성기 — `demo` 및 KRX 접근 불가 시 자동 폴백(데모 17종목) |

> `MARKET_SOURCE=krx`(기본). 시세 서버 접근이 막히면 — 실데이터가 이미 있으면 그대로 두고(kept), 빈 DB 면 생성 데이터로 폴백.
> 환율은 해외 수집(수출입은행/FDR)이 실제 값을 넣고 KRX 적재는 덮지 않는다. 국고채 3년은 아직 상수(별도 소스 필요).

## 2026-10-01 — 검색·자동완성 수정 · 코스피/코스닥 지수 복구 · 추천 Top5 멀티팩터 모델 · 리스크/부실예측

**원인 → 해결**
- 검색: 엔터를 자동완성 결과가 그려진 뒤에만 처리(디바운스 200ms + 해외 검색까지 기다림) → 빠르게 치고 엔터, 한글 마지막 글자 조합 중 엔터는 무시됐다.
  대소문자 구분('sk'·'naver' 0건), 조합 중 글자('삼서') 0건, 결과 순서 무작위, 타이핑 조각이 인기 검색어를 오염.
  → 자모 분해 매칭 + 정확도·시총 랭킹 + 인메모리 색인 + 즉시 조회 엔터 + IME 처리 + ↑↓/Esc + 최근·인기 검색 + 늦은 응답 무시.
- 지수: KRX 지수 API(별도 이용신청 필요)가 401 이면 예외를 삼키고 **상수(3,124.68)를 오늘 날짜·실데이터처럼** 저장. 화면은 해외 지수 호출과 묶여(Promise.all) 함께 대기.
  → `collectors/indexes.py` 다중 소스(KIS 실시간 → 야후 → KRX → FDR) + 출처·기준일 기록 + 실데이터를 상수로 안 덮음 + 장중 백그라운드 갱신 + 화면 분리 렌더·상태 배지·미니차트.
- 추천 Top5: 기술적 신호 점수 합(정수)만 사용 → 7팩터 멀티팩터 모델(reco_engine.py) + 설명 가능성 + 적합성 + 백테스트 + 감사 스냅샷.
